# BarzhaFit Design System

## 🎨 Цветовая палитра

### Основные цвета
- **Primary**: `#030213` - основной темный цвет для акцентов
- **Background**: `#ffffff` - белый фон
- **Card**: `#ffffff` - белый фон карточек
- **Muted**: `#ececf0` - приглушенный серый
- **Border**: `rgba(0, 0, 0, 0.1)` - тонкие границы

### Цвета графиков
- **Chart-1**: оранжевый (калории)
- **Chart-2**: голубой (белок)
- **Chart-3**: синий (жиры)
- **Chart-4**: желто-зеленый (углеводы)
- **Chart-5**: желтый (шаги)

### Семантические цвета
- **Success**: `#22c55e` - зеленый для успеха
- **Danger**: `#ef4444` - красный для ошибок
- **Warning**: `#f59e0b` - желтый для предупреждений

## 📏 Типографика

- **Базовый размер**: 16px
- **H1**: 24px / 1.5 / medium (500)
- **H2**: 20px / 1.5 / medium (500)
- **H3**: 18px / 1.5 / medium (500)
- **H4**: 16px / 1.5 / medium (500)
- **Body**: 16px / 1.5 / normal (400)
- **Small**: 14px / 1.5 / normal (400)
- **Extra Small**: 12px / 1.5 / normal (400)

## 📐 Spacing (8px Grid)

- **xs**: 4px (0.5)
- **sm**: 8px (1)
- **md**: 16px (2)
- **lg**: 24px (3)
- **xl**: 32px (4)
- **2xl**: 48px (6)

## 🔘 Компоненты

### Button
Размеры:
- **sm**: min-height 36px, padding 8px 12px
- **md**: min-height 44px, padding 12px 16px
- **lg**: min-height 52px, padding 16px 24px

Варианты:
- **primary**: основной темный
- **secondary**: светло-серый
- **success**: зеленый
- **danger**: красный
- **ghost**: прозрачный

### Card
- Border radius: 16px (rounded-2xl)
- Padding: 16px
- Border: 1px solid border color

### Input/Textarea
- Min-height: 44px
- Padding: 12px 16px
- Border radius: 12px (rounded-xl)
- Background: `#f3f3f5`
- Focus: ring 2px primary/50%

### Progress Bar
- Height: 8px (h-2)
- Border radius: full
- Background: muted
- Fill: chart colors
- Transition: 500ms

## 📱 Responsive

### Breakpoints
- **Mobile**: 360-430px (default)
- **Tablet**: 520-600px (max-width container)
- **Desktop**: центрирование с max-width 600px

### Safe Area
- Padding: 16px по бокам
- Bottom padding: 24px (для iOS gesture bar)

### Touch Targets
- Минимум: 44×44px
- Рекомендуемый: 48×48px для важных действий

## 🎭 Эмодзи

Используются для визуальной обратной связи:
- ✅ - выполнено
- ❌ - пропущено
- 🟢 - цель достигнута
- 🟡 - в процессе
- 🔴 - не начато
- 💪 - тренировки
- 🍽️ - питание
- 🔥 - серии
- 📊 - статистика
- 🎯 - цели
- 👟 - шаги

## 📱 Экраны

1. **Сегодня** - главный экран с планом дня и прогрессом
2. **Еда** - добавление и просмотр приёмов пищи
3. **План** - редактирование недельного плана
4. **Цели** - установка целевых показателей
5. **Шаги** - ввод и отслеживание шагов
6. **Профиль** - данные пользователя
7. **Статистика** - недельная и месячная статистика
8. **Серии** - визуализация серий тренировок и питания

## 🎨 Стиль

- Спортивный, энергичный
- Прямой язык без "офисности"
- Яркие акценты и градиенты
- Четкая типографика
- Эмодзи для эмоциональной связи
- Визуальная обратная связь (индикаторы, прогресс-бары)
