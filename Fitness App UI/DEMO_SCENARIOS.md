# 🎬 Демонстрационные сценарии

## Полный User Flow

### Сценарий 1: Новый пользователь (Day 1)

**Шаг 1: Открытие приложения**
- Пользователь открывает Mini App
- Видит экран "Сегодня"
- Показывается пустое состояние "Нет плана на сегодня"

**Шаг 2: Настройка профиля**
- Нажимает "Профиль" в навигации
- Заполняет данные:
  - Пол: Мужской
  - Возраст: 25 лет
  - Рост: 175 см
  - Вес: 75 кг
  - Жир: 15%
  - Активность: Умеренная
  - Цель: Сушка (Cut)
- Видит расчётные показатели:
  - BMI: 24.5 (Норма)
  - Базовый метаболизм: 1,750 ккал
  - Дневная норма: 2,450 ккал
  - Для цели: 2,000 ккал
- Нажимает "💾 Сохранить профиль"
- Показывается Toast: "✅ Профиль сохранён!"

**Шаг 3: Установка целей**
- Переходит на "Цели"
- Видит предзаполненные значения из профиля:
  - Калории: 2000 ккал
  - Белок: 150 г
  - Жиры: 60 г
  - Углеводы: 200 г
  - Шаги: 10,000
- Корректирует (если нужно)
- Нажимает "💾 Сохранить"
- Toast: "✅ Цели установлены!"

**Шаг 4: Создание плана**
- Переходит на "План"
- Вводит план на неделю:
```
День 1: Грудь, трицепс
Утро: овсянка с фруктами
Обед: курица, гречка
Вечер: рыба, овощи
Тренировка: жим, отжимания

День 2: Спина, бицепс
...
```
- Нажимает "💾 Сохранить"
- Toast: "✅ План сохранён!"

**Шаг 5: Первый приём пищи**
- Переходит на "Еда"
- В textarea вводит:
```
Овсянка 100г
Банан 1 шт
Молоко 200мл
```
- Нажимает "✅ Добавить"
- Видит приём пищи в списке:
  - 08:30
  - Овсянка 100г, банан, молоко
  - 450 ккал • Б: 15г Ж: 10г У: 70г

**Шаг 6: Отметка тренировки**
- Переходит на "Сегодня"
- Видит план дня
- Видит карточку "💪 Тренировка" со статусом "—"
- После тренировки нажимает "✅ Сделал"
- Статус меняется на "✅"
- Показывается "Отлично! Тренировка выполнена 💪"

**Шаг 7: Ввод шагов**
- Переходит на "Шаги"
- Вводит: 8500
- Нажимает "✅ Сохранить"
- Видит прогресс: 8,500 / 10,000 (85%)

**Шаг 8: Проверка прогресса**
- Возвращается на "Сегодня"
- Видит прогресс по всем показателям:
  - 🟡 Калории: 450 / 2000 (23%)
  - 🔴 Белок: 15 / 150 (10%)
  - 🔴 Жир: 10 / 60 (17%)
  - 🔴 Углеводы: 70 / 200 (35%)
  - 🟡 Шаги: 8,500 / 10,000 (85%)

### Сценарий 2: Обычный день (Day 7)

**Утро:**
1. Открыл приложение
2. Прочитал план дня
3. Позавтракал → добавил еду
4. Проверил прогресс

**День:**
1. Обед → добавил еду
2. Прогулка → автоматически считаются шаги
3. Ввёл шаги: 6,500

**Вечер:**
1. Тренировка → нажал "✅ Сделал"
2. Ужин → добавил еду
3. Проверил итоги дня:
   - ✅ Калории: 2,050 / 2,000 (103%)
   - ✅ Белок: 155 / 150 (103%)
   - ✅ Жир: 58 / 60 (97%)
   - ✅ Углеводы: 195 / 200 (98%)
   - 🟡 Шаги: 6,500 / 10,000 (65%)

**Перед сном:**
1. Посмотрел статистику за неделю
2. Увидел серию: 7 дней тренировок подряд 🔥
3. Получил достижение: "🥇 Неделя без пропусков"

### Сценарий 3: Пропуск тренировки

**Ситуация:** Заболел, не может тренироваться

1. Открыл приложение
2. Перешёл на "Сегодня"
3. Увидел карточку тренировки
4. Нажал "❌ Пропустил"
5. Статус изменился на "❌"
6. Показалось: "Пропущено. Не сдавайся!"
7. Серия тренировок прервалась
8. Посмотрел статистику:
   - За неделю: 6 из 7 тренировок (86%)
   - Прошлая серия: 7 дней

   - Ср: ✅ 🍽️ | 2,200 ккал • 155г белка • 10,800 шагов

   - Калории: 2,050 ккал
   - Белок: 145 г

   - Больше пропусков по выходным
   - Стабильное питание в будни

## Типичные состояния UI

### Пустые состояния (Empty States)

1. **Нет плана:**
   - Экран "Сегодня" при первом запуске
   - Показывается EmptyState с призывом создать план

2. **Нет еды:**
   - Если за день ничего не добавлено
   - Показывается "Приёмов пищи пока нет"

3. **Нет профиля:**
   - Форма с подсказками

4. **Нет истории:**
   - Статистика за прошлые периоды

### Состояния загрузки (Loading)

1. Загрузка данных с сервера
2. Синхронизация с Telegram
3. Расчёт показателей

### Состояния ошибок (Error)

1. **Валидация:**
   - Некорректный вес (< 30 или > 200)
   - Пустые обязательные поля
   - Input с красной обводкой и текстом ошибки

2. **Сеть:**
   - Toast: "❌ Ошибка сохранения. Проверьте подключение"
   - Кнопка "Повторить"

3. **Данные:**
   - Toast: "❌ Некорректные данные"

### Состояния успеха (Success)

1. **Сохранение:**
   - Toast: "✅ Сохранено!"
   - Автоматически исчезает через 3 сек

2. **Добавление:**
   - Toast: "✅ Приём пищи добавлен!"
   - Элемент появляется в списке с анимацией

3. **Достижения:**
   - Toast: "🏆 Новое достижение: Неделя без пропусков!"
   - Визуальное выделение в разделе "Серии"
