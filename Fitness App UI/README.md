# 💪 BarzhaFit - Telegram Mini App

Полноценное фитнес-приложение для Telegram Mini App с отслеживанием питания, тренировок, шагов, целей и статистики.

## 🎯 Основной функционал

### Экраны приложения

1. **Сегодня** 📱
   - План дня
   - Статус тренировки (✅/❌/—)
   - Прогресс по целям (калории, БЖУ, шаги)
   - Приёмы пищи за день

2. **Еда** 🍽️
   - Добавление приёмов пищи (textarea)
   - Список приёмов за сегодня
   - Автоматический подсчёт БЖУ и калорий
   - Удаление приёмов

3. **План** 📅
   - Редактирование плана на неделю
   - Многострочное текстовое поле
   - Описание тренировок и питания на 7 дней

4. **Цели** 🎯
   - Установка дневных целей
   - Калории, белок, жир, углеводы, шаги
   - Пересчёт из профиля
   - Текущий прогресс

5. **Шаги** 👟
   - Ввод шагов за день
   - Прогресс к цели
   - История за неделю

6. **Профиль** 👤
   - Пол, возраст, рост, вес
   - Процент жира
   - Уровень активности
   - Цель (cut/balance/bulk)
   - Расчётные показатели (BMI, метаболизм)

7. **Статистика** 📊
   - Недельная статистика (таблица)
   - Месячная статистика (календарь с эмодзи)
   - Средние показатели

8. **Серии** 🔥
   - Серии тренировок
   - Серии питания
   - Визуальные индикаторы прогресса
   - История серий
   - Достижения

## 🎨 Дизайн-система

### Цвета
- **Primary**: `#030213` - основной тёмный
- **Background**: `#ffffff` - белый фон
- **Muted**: `#ececf0` - приглушенный серый
- **Chart colors**: яркие цвета для графиков и прогресса

### Компоненты
- **Card** - карточки с контентом
- **Button** - кнопки (primary, secondary, success, danger, ghost)
- **Input/Textarea** - поля ввода
- **Select** - выпадающие списки
- **ProgressBar** - индикаторы прогресса
- **Toast** - уведомления
- **EmptyState** - пустые состояния
- **LoadingSpinner** - загрузка

### Типографика
- Базовый размер: 16px
- H2: 20px / medium
- H3: 18px / medium
- H4: 16px / medium
- Body: 16px / normal
- Small: 14px, Extra Small: 12px

## 📱 Responsive дизайн

- **Mobile first**: 360-430px
- **Max width**: 600px (центрирование на планшетах)
- **Safe area**: padding 16px по бокам, 24px снизу
- **Touch targets**: минимум 44×44px
- **Grid system**: 8px базовая сетка
